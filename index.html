Install MySpuds on Your Phone

Put this page on your home screen like an app — one tap and you're straight on your profile, no browser hunting. It takes about 10 seconds:

iPhone (Safari)

  1. Tap the Share button (the square with an arrow pointing up) at the bottom of Safari.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add — done. The MySpuds icon is on your home screen.

Android (Chrome)

  1. Tap the ⋮ menu in the top-right corner of Chrome.
  2. Tap Install app (or Add to Home screen).
  3. Tap Install — done. The MySpuds icon lands on your home screen.

On a computer

  1. In Chrome or Edge, click the install icon at the right end of the address bar (or the ⋮ menu → Install).

            Basement server — real collisions

            Not connected. On the basement server the PC runs the race itself: phones send only gas & steering, the server moves every kart and decides the bumps — so karts actually collide, and finish times come from the server, not the phones.

              No server races waiting right now.

              Set it up once: download the server file, put it on the basement PC, install Node.js (free at nodejs.org), and run node spud-kart-server.js — then leave the PC on while you race. The server window prints the addresses to type above: the 192.168 one works on the same Wi-Fi; friends in other houses install Tailscale, join the same tailnet, and use the PC's 100.x Tailscale address. Up to 4 karts per race. If a browser refuses the ws:// connection from this https page, allow insecure content for this site in its site settings.
