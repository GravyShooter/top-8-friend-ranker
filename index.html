Install MySpuds on Your Phone

Put this page on your home screen like an app — one tap and you're straight on your profile, no browser hunting. It takes about 10 seconds:

iPhone (Safari)

  1. Tap the Share button (the square with an arrow pointing up) at the bottom of Safari.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add — done. The MySpuds icon is on your home screen.

Android (Chrome)

  1. Tap the ⋮ menu in the top-right corner of Chrome.
  2. Tap Install app (or Add to Home screen).
  3. Tap Install — done. The MySpuds icon lands on your home screen.

On a computer

  1. In Chrome or Edge, click the install icon at the right end of the address bar (or the ⋮ menu → Install).

              Server setup — one time, host only (friends never touch this)

              One-click setup: download the setup file onto the basement PC and double-click it. It installs Node.js if it's missing, downloads the server, sets it to start itself every time the PC turns on, and starts it right away. No terminal, no typing — and after that one double-click there is nothing to run or click ever again; the server is simply on whenever the PC is. If Windows warns about the download, click More info → Run anyway — it's just this setup file. (The server file itself, if you ever want it on its own.) If Windows Firewall asks while the server starts, click Allow access — that's the phones reaching the server.

              Type the server's address once — the server window prints it when it starts (the 192.168 one works on the same Wi-Fi; the 100.x Tailscale one works from anywhere, for friends in other houses on the same tailnet). This device remembers it from then on, and it travels inside race invite links so friends never type anything at all. Up to 4 karts per race, 2 laps on the server's Oval — that's the 8th layout; the 7 Grand Prix tracks above are solo vs the AI.
